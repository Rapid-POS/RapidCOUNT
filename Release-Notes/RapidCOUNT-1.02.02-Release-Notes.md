# RapidCOUNT v1.02.02 Release Notes

**Release Date:** June 17, 2026

_Audio alerts for scan problems, individual cell-quantity editing, and a smoother grid count layout — plus fixes that keep gridded item details accurate while you edit._

## New Features & Improvements

### Audio alerts for scan problems

RapidCOUNT now plays a sound when a scan runs into a problem, so you can catch issues without watching the screen during a count.

- You'll hear an alert when you scan an item that isn't on file.
- Common error messages now play an audio notification, making scan issues easier to recognize mid-count.

### Edit each gridded cell quantity on its own

You can now change the quantity in a single gridded cell without affecting the others, making grid counts easier to correct.

### Smoother grid counts

We improved the grid count layout and the scrolling experience, so working through gridded items feels cleaner.

## Bug Fixes

### Gridded item details no longer appear blank

We fixed inconsistent bottom-sheet behavior that could leave gridded item details blank or rendered incorrectly.

### Selected gridded items now show the right details

We fixed an issue where a selected gridded item didn't always display its expected cell details.

### Editing one gridded item no longer affects others

We fixed an issue where selecting a specific gridded item could change other gridded items on the edit list.
