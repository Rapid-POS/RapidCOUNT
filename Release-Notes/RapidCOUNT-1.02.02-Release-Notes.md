# RapidCOUNT v1.02.02 Release Notes
**Release Date:** June 17thn  2026

_Audio feedback enhancements and gridded item workflow improvements, plus fixes for gridded item display and editing behavior._

## New Features & Improvements

### Audio Feedback for Scan Issues
New audio feedback makes common scanning issues easier to recognize during inventory counts.

- Added audible feedback when scanning an item that is not on file.
- Added audio notifications for common error messages.

### Gridded Item Workflow Improvements
Editing and navigation for gridded items has been improved.

- Each gridded cell quantity can now be modified individually.
- Improved the grid count layout and scrolling experience.

## Bug Fixes

### Gridded Item Display and Editing
Multiple issues affecting gridded item display and editing behavior have been resolved.

- Fixed inconsistent bottom sheet behavior that could cause gridded item details to appear blank or render incorrectly.
- Fixed an issue where selected gridded items did not always display the expected cell details.
- Fixed an issue where selecting a specific gridded item could affect other gridded items on the edit list.
